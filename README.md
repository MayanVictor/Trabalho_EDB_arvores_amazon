# Trabalho_EDB_arvores_amazon

## Autor
- feito por: Mayan Victor.
- intituição: UFRN.
- Disciplina: Estrutura de Dados Basico.

## Objetivo
-Comparar AVL e Rubro-Negra no gerenciamento de identificadores de encomendas

## Funcionalidades
- Inserção, remoção, busca, percurso, impressão, estatísticas e validação

## Decisões
-Identificadores inteiros, rejeição de duplicatas e tratamento de elementos inexistentes

## Exemplo de Uso
-Inserir 10, 20, 30, mostrar a árvore, buscar 20 e remover 10

## Dependências
-Compilador C++ com suporte a C++17

## Testes
-Cenários executados e localização dos registros, caso estejam no repositório

## compile e execute
compile o projeto no vs code usando:
```bash
g++ -std=c++17 -Wall -Wextra main.cpp AVL.cpp RubroNegra.cpp -o arvores.exe
```
então execute com:
```bash
.\arvores.exe
```
